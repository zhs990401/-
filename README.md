# 中国港湾账目核对平台

财务核对网页工具，支持三项独立功能：

1. **多项目往来**：一次导入多个项目的往来明细，只核对互为对方的项目，如 A→B 对 B→A，借贷方向相反。提供项目两两发生额汇总与逐笔差异。
2. **银行资金**：逐个银行账户比较内账、外账或银行流水，单独统计疑似银行手续费，并支持唯一的一笔对多笔组合。
3. **项目现金流**：按银行流水的 `project` 列分类，以手工期初日期和余额为起点，逐月统计各项目、各币种的收入、支出、净额与余额，支持跨月保存工作包。

各功能页面提供“银行示例”“多项目示例”和“现金流示例”。示例为虚构数据，不包含真实账务信息。

左侧分为“项目往来核对”“银行资金内外账核对”“项目现金流统计”三个独立功能。切换时保留各自数据、规则和结果。页面刷新后需重新导入数据；现金流功能也可读取你事先保存的本地工作包恢复设置和明细。

## 一、一次性核对多个项目的原币往来

推荐每个项目导出同一期间的**往来辅助明细账**，包含往来辅助对象与原币发生额，保存为 Excel。建议文件名直接用 `项目A.xlsx`、`项目B.xlsx`，无需手工合并项目报表。

1. 点击左侧“项目往来核对”，点击“批量选择文件”一次选择多个项目。最多 20 份、合计 60,000 行。常见单行表头可以自动识别；存在“明细”工作表时优先选择明细，可手动调整工作表及表头所在行。多层合并表头尚需整理为一行，不能保证自动识别所有财务软件导出格式。
2. 系统用文件名预填本方项目，可修改。文件名若带日期或“往来明细”等附加文字，请改为标准项目名称。如果表里有“本方项目／账套名称”列，可直接映射，以该列优先；一张合并表里包含多个本方项目也支持。
3. 选择**对方项目／往来单位**列。系统不会从摘要或科目名称自由猜测对方项目；没有往来对象列时需要先整理。项目名称不一致，可在“项目名称对照”按 `别名=标准名称` 填写，双方按同一对照表转换，导出仍保留原名称。
4. 默认只核对**原币发生额**。优先识别“原币借方发生额／原币贷方发生额”，支持“借方(原币)／贷方(原币)”等常见变体，也支持带正负号的单列原币发生额。明确标为本币、本位币、折合金额或余额的列不能作为原币发生额；泛称“借方金额／贷方金额”时，需要你明确勾选确认是原币，不能自动认定。
5. **原币币种必须明确**：选择每行币种列。文件确实只有一种币种且没有币种列时，可以填写单一币种，如 USD；不会默认人民币。有币种列但某行为空的记录会列为无效，不使用单一币种设置补猜。USD／美元、CNY／人民币等常见名称会规范为一致代码，但不做汇率换算。双方金额单位也应一致。
6. 同格式文件可先设置一份，再点击“将字段设置应用到相同表头文件”。只对表头及顺序相同的文件复制字段和币种设置，**不会覆盖各文件本方项目名称**；手填单一币种时，务必确认所有目标文件的币种确实相同。
7. 导入检查清单会展示每份文件、本方项目、所选原币金额列、币种来源、记录数和待确认事项。完成必要确认后才能开始。内容完全重复的同一项目文件会被拒绝，避免重复计算。
8. 可设置统一开始／结束日期，留空比较全部导入发生额；范围外记录保留在导出报告中。各文件实际交易日期范围不同会提示，但没有交易也可能导致日期范围不同，不会仅凭此判断导出不完整。
9. 点击“开始核对”，系统按**项目A→项目B 对 项目B→项目A，原币币种相同，借贷相反**比较。不同项目组合、不同币种不交叉配对；缺少对方账簿、单边记录、原币金额差异、日期超范围和重复候选均保留。双方各自账套的凭证号通常不同，默认不强制相同。
10. 查看“项目两两原币往来汇总”，可按项目组合和原币币种筛选汇总及明细。净额相等仍可能存在逐笔差异，不会只看项目总体净额抵销。

### 本币金额单独查看

可以保留本币借方／贷方金额和本币币种，也可手工映射这部分辅助字段。**原币配对成功且双方本币币种相同时**，本币金额不同会放入“本币金额差异”，不计入原币往来差异；一笔对多笔会按成员合计比较本币。只说明本币金额不同、可能与折算有关，并不自动认定原因就是汇率。

本币资料缺失、无效或币种不同时，仅比较原币并提示本币未比较，不换算币种。原币金额不同，即使本币金额相等，也不会判为原币一致。科目编码、科目名称、本币金额和原始行号都保留在导出报告中供回查。

### 导表模板与核对范围

页面可下载“内部往来原币导表模板”，仓库也提供 `examples/内部往来原币导表模板.xlsx`。推荐字段：本方项目（可由文件名代替）、对方项目、记账日期、原币币种、原币借方／贷方发生额、凭证号、摘要、科目编码／名称；本币币种与金额为可选辅助资料。

**当前核对的是导入期间的原币发生额，不是期末余额。** 期初余额、余额方向、历史结转没有自动核对；需要审查历史余额时，应另外核实往来辅助余额表。请勿把期初余额、月度合计、累计等汇总行当作逐笔明细。

完整 Excel 报告包含原币匹配和差异、本币金额差异、项目汇总、导入检查、期间外记录、所选列与规则。CSV 明细也保留科目、本币辅助字段和差额；汇总及导入检查请使用完整 Excel。

`examples/项目A往来.xlsx`、`项目B往来.xlsx`、`项目C往来.xlsx` 是虚构原币示例，带本方项目列，上传后即可识别：A↔B 为 USD 1000 对 600＋400，原币一致而本币差 CNY 100；A↔C 原币差 USD 10；缺少 D 项目账簿会提示。

## 二、银行资金与手续费核对

1. 点击左侧“银行资金内外账核对”，再选择“内账 ↔ 外账”或“账簿 ↔ 银行流水”。两侧按同一项目、同一期间导出**银行存款明细**。不要混入其他会计科目的完整分录，否则资金会重复计算。每份文件必须映射银行账户列，或填写本文件所属账户。选择“本次核对银行账户”，每次只核对该账户；多账户表可切换账户逐个运行。不同账户不会相互配平。账户名称或账号须一致，缺少账户及其他账户的行在 Excel 报告的“账户范围说明”中保留来源和行号。
2. 映射日期、借方/收入、贷方/支出；也支持一列正数收入、负数支出的金额。金额按分处理，未映射币种时默认 CNY，不做汇率换算。
3. 默认同向：收入对收入、支出对支出。不同银行导出借贷含义可能不同，请确认后手动选择对应金额列。
4. **手续费单独统计**：开启后依据摘要中的关键词识别，默认包含“手续费、汇划费、结算费、账户管理费、网银服务费、银行工本费”，可以修改。两份表都应映射摘要；缺少摘要映射会明确警告。
5. 手续费支出和退款分别统计，币种分开列示。外账单列但内账未找到的费用标记为“疑似内账漏记”；也列出相反方向的单边记录、手续费双方金额差异、重复候选和已匹配手续费。完整 Excel 报告保留双方笔数、支出、退款、规则调整后的差额和疑似漏记统计。
6. **手续费单列不等于已核平，也不会自动补账。** 全部有效明细净额仍包含手续费；普通交易和手续费分开比较，不将手续费混进普通交易组合来消除差异。

关键词识别是辅助分类，可能误分类或漏识别。普通服务费不一定是银行手续费；不要仅凭两笔付款相差几元就认定是手续费。若费用包含在一笔总扣款中且没有单独明细，当前只会列出金额差异，需要查看银行回单确认。可调整关键词或关闭单列功能后重新核对。

## 三、项目全周期现金流

1. 点击左侧“项目现金流统计”，导入 Excel 银行流水，可以追加多个账户和月份的文件。表中必须有项目归属列，名字 `project` 会自动识别，也可手动映射；项目名称按去除首尾空格后的值精确分类。
2. 确认日期、收入/支出、project、币种和账户映射。一列金额时选择正数收入、负数支出。不同币种独立汇总，不进行汇率换算。账户列用于区分来源和重复候选；没有账户列时建议填写该文件的银行账户。
3. 点击“从 project 列添加项目”，手工填写各项目、各币种的**期初日期、期初余额**。该余额是期初日期当天业务发生前的余额；当天流水计入，之前的流水会列入范围外记录。期初余额可为负数，确认为零时应填写 `0`，不会将空值当成零。
4. 选择统计截止日，留空时到最新导入流水或期初日期。只有部分月份的流水不能代表项目从成立至今的数据完整；请以项目实际起始日期设置期初并导入整个期间的流水。
5. 查看项目累计收支与月度表：**月末余额 = 月初余额 + 当月收入 − 当月支出**，下月月初承接上月月末。没有记录的月份也展示余额滚动，但明确标为“无导入记录”，不证明该月没有发生业务。月初/期末余额包括手工期初，累计收入/支出只包括本次计入的流水，不包含期初之前的累计发生额。
6. 没有设置期初的项目仍统计收入、支出与净额，但余额显示为空，不虚构初始余额。需要添加期初时可补充后重算。期初日期与银行账务范围应由你确认。
7. project 为空、日期/金额无效的记录单独列出，不分摊给其他项目；统计截止日之后和期初之前的记录也保留来源及排除原因。银行手续费如没有 project，不会自动猜测属于哪个项目。
8. 重复候选按账户、币种、日期、金额与流水号判断；缺少流水号时参考项目和摘要。没有账户信息时只能按文件内容限制判断范围，建议补充账户。**这些只是疑似重复，并非已确认的重复交易**；默认全部暂不计入。可删除重复文件或核实后勾选“均为独立交易，全部计入”。同一金额、摘要的真实独立交易也可能被提示，必须人工确认。
9. 下载“现金流 Excel 报告”包含项目汇总、全部月度、手工期初、计入明细、无效/未分类/重复/期间外记录及统计规则，保留原文件和行号。图表展示选定项目、币种的最近 24 个月，完整期间见月度表和导出报告。
10. 跨月使用：点击“保存工作包”，下次“读取工作包”后再追加新的流水月份。工作包是含财务明细和期初情况的 JSON 文件，请自行安全保管；它不包含原 Excel 样式，读取后若要重新选择工作表/表头，需要重新导入原 Excel。平台不自动存储工作包或账表。请勿将真实工作包提交到 GitHub。

当前按银行收支口径统计，**含账户间调拨、未自动抵销内部转账**，不是自动编制经营/投资/筹资分类的现金流量表。导入遗漏、分类错误或人为期初错误都会影响结果。支持最多 20 份、合计 60,000 行、500 个项目与币种组合，每个组合最长 600 个月；月度输出最多 120,000 行。

可试用页面的虚构示例，或导入 `examples/项目现金流示例.xlsx`：项目A期初 100 元，2026 年 1—3 月累计收入 1500 元、支出 500 元，期末 1100 元；项目B期末 700 元；5 元银行手续费缺少 project，单列为未分类。

## 四、一笔对多笔规则

- 银行审核和多项目往来均可开启，默认开启。**先完成唯一一对一配对，再对剩余且没有一对一冲突的记录进行组合搜索。** 因此精确的一对一优先于金额可拆分的其他组合。
- 支持左右互换：左侧 1 笔对右侧 2–5 笔，或左侧 2–5 笔对右侧 1 笔。可设置每组最多 2、3、4、5 笔；多笔对多笔尚不支持。
- 成员金额必须同方向，合计精确相等，不用一正一负相抵来凑数；同币种，并满足日期、账户（如开启）及严格参考号规则（如开启）。项目往来还要求本方/对方互为对应。
- 日期窗口以单笔一侧为基准，每个成员与该日期的差不超过容差，默认同一天，最大 31 天。
- **只有唯一且不与其他组合共用记录的组合才自动配对。** 多个组合可配平或不同组合共用同一成员时均保留为待人工复核，不贪心挑选第一个组合。
- 每个单笔最多搜索 18 条候选，每次分类/项目组合搜索最多 200,000 个子集。超过上限会明确提示，本轮组合不自动配对，不会将未穷尽的搜索宣称为唯一匹配。可以按期间、账户或可对应的业务参考号缩小范围。
- 组合的每个成员保留文件、工作表、原始行号、金额。报告中会显示组合成员和合计，Excel/CSV 导出也不会仅保留一条合计而丢失成员。

## 通用准备与限制

- 支持 `.xlsx`、旧版 `.xls`、UTF-8/GB18030 CSV。每份最多 10 MB、30,000 条、100 列。可选择工作表和表头所在行。
- 删除期初余额、本月合计、累计等汇总行。金额为空/零、日期无效、同一行借贷同时有金额等记录单独列为无效数据，不计入有效净额。数据异常不等于交易没有发生。
- Excel 公式不会执行；`.xlsx` 公式会警告，用于比较的公式列请先粘贴为值。`.xls` 使用文件内保存的值，请先在 Excel 重新计算并保存。数字型参考号可能丢失显示用前导零，请优先以文本导出。
- 唯一一对一匹配中，相同非空参考号优先；不开启严格参考号时，金额、日期等条件唯一也可配对，不代表已经核实为同一业务。组合搜索仅在开启严格参考号时强制每个成员参考号相同。不同账簿的凭证号不一定是共同业务号，不要未经确认就开启严格匹配。
- 普通差异与手续费分开显示；重复候选不自动抵销。报告可以搜索文件、项目、摘要、参考号和原因。
- 下载“完整 Excel 报告”可获得逐笔分类、组合成员、项目汇总、手续费汇总、净额汇总、规则和提示。金额以两位小数文本保存以保留分币精度；下载的 Excel 不包含公式，导入文本不会变成可执行公式。CSV 仅包含明细分类，完整汇总请使用 Excel。
- 向他人提供样表前请脱敏：隐去完整银行账号、个人信息及敏感单位名称。相同对象在各份样表中使用一致代号，保留列名、日期、金额方向与几条已知差异。

结果用于辅助定位差异，不能替代原始凭证核实和专业审计；正式使用前请用业务人员确认过的样本校准规则。

## 本机启动

Windows 初次使用：先将 ZIP **全部解压**，安装 Python 3.10 或更新版本，然后双击文件夹中的 **`启动网页.bat`**。它会自动创建运行环境、安装依赖并打开浏览器。请保持命令窗口打开；如果失败，窗口会保留错误信息，不会一闪而过。首次安装依赖需要联网。不要直接双击 `server.py`。

需要 Python 3.10 或更新版本。在项目文件夹执行：

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python server.py
```

Windows 使用：

```powershell
py -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python server.py
```

保持终端打开，在**运行程序的同一台电脑**的浏览器地址栏输入 `127.0.0.1:8000`，按 Ctrl+C 停止。端口被占用可运行 `server.py --port 8001` 并使用对应端口。

上述 `server.py` 是本机入口，仅监听本机。另提供带访问账号和密码保护的线上入口，参见 [Render 网页部署步骤](DEPLOYMENT.md)。部署文件不会自动创建网站，需要在 Render 连接 GitHub 并创建服务。

本机运行时上传内容在本机处理；上线后文件会上传到你托管服务的进程中处理。程序不将账表写入磁盘或数据库，不发送至外部分析服务。没有多用户角色和历史保存，刷新页面后需重新上传或读取自行保存的现金流工作包，导出的报告和工作包由使用者自行保管。
